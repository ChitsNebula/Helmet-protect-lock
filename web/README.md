# 🪖 Helmet Dataset Collector - Web Application

ระบบถ่ายรูปเก็บ Dataset หมวกกันน็อกอัตโนมัติผ่านเว็บเบราว์เซอร์ ใช้งานได้ทั้งบนโทรศัพท์มือถือและคอมพิวเตอร์ รองรับการโฮสต์บน **Vercel** และส่งไฟล์ภาพขึ้นบันทึกลง **Google Drive** โดยตรง

---

## ✨ จุดเด่นและฟีเจอร์

1. **เปิดผ่านเบราว์เซอร์ได้ทันที:** คนอื่นไม่ต้องลง Python หรือโปรแกรมใดๆ แค่ส่งลิงก์เว็บให้ สามารถเปิดกล้องถ่ายภาพได้ทันที
2. **รองรับสมาร์ทโฟนเต็มรูปแบบ:** สลับกล้องหน้า/กล้องหลังได้ พร้อมโหมดกระจก (Mirror)
3. **ระบบ Auto-Capture:** ตั้งเวลาหน่วง (1.0s, 1.5s, 2.0s) และจำนวนเป้าหมายได้ พร้อมกรอบเล็งศีรษะและหมวกกันน็อก
4. **บันทึกลง Google Drive แยกโฟลเดอร์:** รูปจะถูกส่งขึ้น Google Drive อัตโนมัติ พร้อมจัดหมวดหมู่โฟลเดอร์ตามคลาส (`with-helmet` / `without-helmet`)
5. **ระบบสำรอง (Offline Fallback):** มีปุ่ม **"ดาวน์โหลด ZIP"** รวบรวมภาพทั้งหมดในเซสชันนั้นเป็นไฟล์ .zip ได้ทันทีในคลิกเดียว

## 🚀 วิธีเอาขึ้น Vercel (Deployment Guide)

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ - อัปเดตอัตโนมัติ)
1. ดันโฟลเดอร์นี้ขึ้น GitHub ของคุณ
2. เข้าไปที่ [Vercel Dashboard](https://vercel.com/dashboard)
3. กด **Add New...** -> **Project** -> เลือก Repository `Helmet-protect-lock`
4. ตรงส่วน **Root Directory** ให้กด Edit แล้วเลือกเป็นโฟลเดอร์ `web`
5. กดปุ่ม **Deploy** แล้วรอประมาณ 1 นาที จะได้ URL เว็บพร้อมใช้งานทันที!

### วิธีที่ 2: Deploy ด้วยคำสั่ง Terminal (Vercel CLI)
เปิด Terminal ในโฟลเดอร์ `web` แล้วสั่ง:
```bash
npx vercel
```
ทำตามขั้นตอนบนหน้าจอ ล็อกอินแล้วกด Enter ระบบจะ Deploy ขึ้น Vercel ให้ทันที

## 📁 วิธีเชื่อมต่อ Google Drive (ทำครั้งเดียวใน 2 นาที)

1. ไปที่ Google Drive สร้างโฟลเดอร์ใหม่ (เช่น `Helmet_Dataset`)
2. เปิดดู URL ของโฟลเดอร์นั้น แล้วคัดลอก **Folder ID** (ชุดตัวอักษรท้ายลิงก์ เช่น `1A2b3C4d...`)
3. ไปที่ [Google Apps Script](https://script.google.com/home) -> กด **โครงการใหม่ (New project)**
4. ลบโค้ดเดิมออกทั้งหมด แล้วนำโค้ดจากไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ไปวาง
5. แทนที่ `PUT_YOUR_GOOGLE_DRIVE_FOLDER_ID_HERE` ด้วย Folder ID ของคุณ
6. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - การเข้าถึง (Who has access): **ทุกคน (Anyone)**
7. คัดลอก **URL เว็บแอป (Web app URL)**
8. เปิดหน้าเว็บของคุณ -> กดปุ่ม **ตั้งค่า (ฟันเฟือง)** ขวาบน -> วาง URL ลงในช่องแล้วกดบันทึก จบเลย!
